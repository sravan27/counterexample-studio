- Reference-versus-target differential runner

## Prior Public Evidence, Not Reused Product Code

The project is informed by the creator's public `silentdrop` corpus and merged database correctness fixes. Those artifacts establish that silent semantic divergence is a real developer problem. Counterexample Studio does not present prior code as Build Week work; the submission identifies every prior reference and every new component separately.

The historical verifier installs two exact, attributed PowerSync npm releases as development fixtures. It does not copy or claim their implementation. The new Build Week work is the differential harness, minimization, provenance capture, integrity binding, CI verification, and studio presentation around those public packages.
