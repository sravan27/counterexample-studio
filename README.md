# Counterexample Studio

**The executable specification laboratory for AI-built data features.**

Counterexample Studio turns a plain-English data invariant into a deterministic contract, compares a target implementation with a small reference model, detects silent semantic divergence, minimizes the failure to its smallest operation trace, and exports a runnable regression test plus evidence bundle.

The project is new work created during OpenAI Build Week. It builds on a public problem history, not pre-existing implementation: the creator previously earned $1,000 completing PowerSync correctness work and shipped merged fixes for silent wrong-data behavior across open-source sync and database engines. Counterexample Studio productizes the missing workflow between an expected behavior and a maintainer-ready minimal proof.

The implementation, hosted demo, architecture, tests, and Build Week provenance are in progress.
